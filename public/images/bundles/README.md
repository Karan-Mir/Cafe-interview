# Bundle artwork

Generated with OpenAI's built-in ImageGen and exported as 720×480 WebP files.

The prompt set requested three separate premium 3D editorial product still lifes for a Persian café research interface. Every image uses the same warm ivory studio, muted sage-green materials, restrained brass accents, soft diffused lighting, centered 3:2 composition, generous negative space, and no text, numbers, logos, people, coffee cups, or implied price tier. The individual scenes vary only in their neutral abstract objects: a layered planning card, balanced modular tiles, and a compact operational dashboard sculpture.

The equal art direction is intentional: packages are randomized by the conjoint design, so the artwork differentiates cards without implying that any bundle is better.
